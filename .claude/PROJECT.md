# 프로젝트 개요

- 광화문 BTS 공연을 위한 편의시설은 공연 특화 페이지 이기 때문에 분리
- 페이지는 세개로 관리 
  - 광화문 BTS 공연 편의시설 페이지
  - 백화점, 스타필드 등 대형 쇼핑몰의 편의시설(펀의점, 흡연구역, 화장실) 위치를 지도에서 확인 할 수 있는 페이지
  - 서울 공공 무료 화장실 위치 지도 표시 페이지


- 백화점 스타필드 대형 쇼핑몰의 편의시설
    - 편의점, 흡연구역, 화장실
    - 무료 API 로 확인이 되지 않는다면 크롤링으로 확인
    - 지도 상의 위치 표시가 어렵다면 각각의 위치가 어디에 있는지 팝업으로 확인 예) 흡연구역 A동 3층
