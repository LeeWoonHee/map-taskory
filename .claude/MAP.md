### 프로젝트

# 페이지

- 화장실
  - 메인페이지에서 바로 지도를 볼수 있게 해줘
  - 지도에서는 화장실 뱃지를 클릭 시 화장실 정보를 볼 수 있게해줘
  - 화장실 정보는 이름, 주소, 운영시간, 변기 수, 관리기관 정보를 보여줘
  - 화장실 정보는 모달로 보여줘
  - 화장실은 https://data.seoul.go.kr/dataList/OA-22586/S/1/datasetView.do 해당 사이트에서 공공 api 를 활용해서 위치에 그려줘

- 쇼핑몰(스타필드, 타임스퀘어, 백화점, 코엑스 등등) 흡연구역
  - 쇼핑몰의 위치와 해당 쇼핑몰의 흡연구역을 지도에 표시해주거나 혹은 쇼핑몰 아이콘 클릭시 어디에 위치해 있는지 텍스트로 알려줘
  - 흡연구역을 찾지못한다면 mock 데이터로 텍스트 작성해줘 (추후 직접 작업 예정)

- 약국
  - https://www.data.go.kr/data/15149539/openapi.do 해당 사이트에서 공공 api 를 활용해서 위치에 그려줘
  - 약국의 영업 시간, 대표전화번호, 주소가 있다면 위치의 아이콘 클릭시 모달창으로 보여줘
  - 대표전화번호, 주소 옆에는 복사 버튼을 만들어서 복사가 바로 가능 하도록 만들어줘

# 기능

- 번역은 영어와 일본어 한국어로 해줘 (한국어가 기본)
